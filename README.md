# Табло — пульт трансляции для OBS

Плагин OBS Studio для хоккейного табло
([hockey-scoreboard-server](https://github.com/TimeOfTheStars/hockey-scoreboard-server)):
пульт трансляции своего поля прямо в окне OBS.

- **Док «Табло»** — счёт с кнопками «Гол» у каждой команды и окном «кто
  забил → передачи», снять последний гол, отмена последнего действия; что
  сейчас в кадре, плашка со счётом (показать / всегда / скрыть),
  полноэкранная графика (составы, итог), повтор титра гола. Внутри —
  страница с сервера, поэтому пульт обновляется вместе с сервером, без
  переустановки плагина.
- **Графика в сцену одной кнопкой** — плагин сам заводит браузерные
  источники 1920×1080 с прозрачным фоном: плашку и полноэкранную графику
  поверх неё, с правильными адресами.
- **Горячие клавиши OBS** — плашка, составы, итог, убрать графику, повтор
  титра гола.
- **Только своё поле.** Плагин привязан как пульт трансляции поля: счёт, голы
  и графику своего поля он ведёт как пульт поля, а время — общее для катка —
  с этого компьютера не меняется: оно за пультом времени.

## Установка

Скачайте последнюю версию со страницы
[Releases](https://github.com/TimeOfTheStars/hockey-scoreboard-obs/releases/latest).
Нужен **OBS Studio 30.2 или новее**.

**Windows.** Запустите `hockey-scoreboard-obs-…-windows-x64-Installer.exe` и
нажмите «Установить». Плагин встанет в
`C:\ProgramData\obs-studio\plugins\hockey-scoreboard-obs\`; если OBS открыт,
установщик предложит его закрыть. Удаляется плагин как обычная программа —
через «Параметры → Приложения». Без установщика: распакуйте
`…-windows-x64.zip` в `C:\ProgramData\obs-studio\plugins\`.

**macOS.** Откройте `hockey-scoreboard-obs-…-macos-universal.pkg`. Установщик
не подписан, поэтому macOS спросит подтверждение: «Системные настройки →
Конфиденциальность и безопасность → Всё равно открыть». Плагин ставится в
`~/Library/Application Support/obs-studio/plugins/`. Перезапустите OBS.

**Linux (Ubuntu).** Установите `.deb` из релиза.

## Подключение

1. На экране подготовки табло: **«Пульты и OBS»** → у нужного поля
   **«Подключить OBS»**. Появится шестизначный код — он действует 10 минут и
   срабатывает один раз.
2. В OBS: меню **Табло → Подключить к табло…**. Адрес сервера
   (по умолчанию `https://scoreboard.timeofthestars.ru`) и код.
3. Появится док «Табло», а OBS предложит добавить графику поля в текущую
   сцену. Позже это же — **Табло → Добавить графику в текущую сцену**.

Код пульта поля или пульта времени сюда не подойдёт: сервер его отклонит и
не сожжёт — для OBS нужен код именно «Подключить OBS».

Привязка живёт год. Отключить OBS можно и в самом OBS (**Табло → Отключить
этот OBS**), и на экране подготовки — тогда пульт перестанет работать сразу.

## Горячие клавиши

**Настройки → Горячие клавиши**, раздел «Табло»:

| Действие | Что делает |
|---|---|
| Табло: плашка — показать/скрыть | плашка со счётом уезжает и приезжает |
| Табло: составы — показать/убрать | составы обеих команд на весь экран |
| Табло: итог — показать/убрать | итоговый счёт и авторы голов |
| Табло: убрать полноэкранную графику | составы и итог уходят из кадра |
| Табло: повторить титр гола | ещё раз показать титр последнего гола |

Клавиши работают и при закрытом доке.

## Источники

Плагин заводит два браузерных источника на поле:

| Источник | Что в нём |
|---|---|
| `Табло: плашка, поле A` | плашка со счётом, титры голов и удалений |
| `Табло: графика, поле A` | полноэкранная графика: составы, итог, награждение |

Ставьте их поверх камеры; полноэкранная графика должна быть выше плашки —
плагин так и добавляет. Если ссылки на сервере перевыпустили, достаточно
подключить OBS заново: адреса в источниках обновятся сами.

## Как устроено

- Привязка — тем же кодом, что и пульты у полей; плагин получает пропуск
  пульта трансляции и хранит его в папке настроек OBS (`config.json`).
- Док открывает `/dock?field=A` сервера с пропуском после `#`: на сервер и в
  журналы эта часть адреса не уходит, страница меняет её на обычную cookie.
- Горячие клавиши — запросы `POST /api/obs/action`, адреса графики —
  `GET /api/obs/setup`. Запросы идут через libcurl в фоновом потоке, чтобы
  OBS не замирал.

## Сборка

Плагин собран на [obs-plugintemplate](https://github.com/obsproject/obs-plugintemplate)
и собирается в GitHub Actions под Windows, macOS и Ubuntu. Сборка идёт против
OBS 30.2.3 — так плагин грузится и в 30.2, и в более новых версиях.

Локально:

```sh
# macOS (нужен Xcode)
cmake --preset macos && cmake --build --preset macos
# Windows (Visual Studio 2022)
cmake --preset windows-x64 && cmake --build --preset windows-x64
# Ubuntu
cmake --preset ubuntu-x86_64 && cmake --build --preset ubuntu-x86_64
```

Релиз — тегом вида `1.0.0`: CI соберёт установщики (Windows — Inno Setup,
macOS — pkg, Ubuntu — deb) и выложит их черновиком в Releases.
